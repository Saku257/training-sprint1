# 要件定義書: P002 検索結果画面

## 目的

キーワード検索またはカテゴリ選択の結果を一覧表示し、入居者が目的のFAQを素早く特定してP003（FAQ詳細画面）へ進めるようにする。検索結果が0件の場合はP004（AIチャット画面）へスムーズに誘導する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | 検索結果一覧表示 | キーワードまたはカテゴリに合致するFAQをリスト形式で表示する | 新規 |
| 2 | 検索キーワード再入力 | 検索バーを上部に固定し、キーワードを修正して再検索できる | 新規 |
| 3 | FAQ詳細への遷移 | 結果リストの各カードタップでP003（FAQ詳細画面）へ遷移する | 新規 |
| 4 | 0件時のAIチャット誘導 | 検索結果が0件の場合に誘導バナーとAIチャットボタンを表示する | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| 検索結果一覧表示 | キーワードまたはカテゴリID（URLクエリパラメータ） | FAQデータをキーワード全文検索またはカテゴリIDでフィルタし、関連度順に並び替え | 件数テキスト＋FAQカードリスト（タイトル・カテゴリタグ・冒頭テキスト2行） |
| 検索キーワード再入力 | 修正したキーワード（テキスト入力）※最大50文字。空白のみの入力は検索を実行しない | バリデーション通過後、既存クエリパラメータを上書きして再度検索処理を実行 | 検索結果リストの更新（件数・カード一覧の再描画） |
| FAQ詳細への遷移 | FAQ ID（カードタップ） | FAQ IDをURLパラメータとしてP003へルーティング | P003（FAQ詳細画面）への遷移 |
| 0件時のAIチャット誘導 | なし（検索結果0件の状態） | 取得結果件数が0であることを検知 | 「見つかりませんでしたか？」メッセージ＋「AIに聞く」バナーボタンの表示 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| 検索結果リスト | 検索結果一覧表示 | `ローディング（スケルトンカード表示）` → `結果あり（カードリスト表示）` → `0件（バナー表示に切り替え）` → `エラー（「読み込みに失敗しました」メッセージ）` |
| 検索バー | 検索キーワード再入力 | `入力済みキーワード表示（初期）` → `編集中（カーソル表示・クリアボタン出現）` → `再検索送信（ローディング）` |
| 検索ボタン | 検索キーワード再入力 | `無効（空白のみ or 未入力）` → `有効（有効文字1文字以上・最大50文字）` → `ローディング（再検索中）` → `有効（結果更新後）` |
| 「AIに聞く」誘導バナー | 0件時のAIチャット誘導 | `非表示（結果あり時）` → `表示（0件時）` → `遷移（P004へ）` |
| FAQカード | FAQ詳細への遷移 | `デフォルト` → `タップ中（押下エフェクト）` → `遷移（P003へ）` |
