# 要件定義書: P004 AIチャット画面

## 目的

入居者がテキストで自由に質問し、AIがマニュアルをもとに即座に回答するチャットインターフェースを提供する。AIが回答できない場合はサポートデスクへの連絡先をチャット内にシームレスに挿入し、有人対応へ迷わず引き継げるようにする。スマホキーボード表示時も入力フォームが見え操作できるモバイルファースト設計を徹底する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | AI質問入力・送信 | テキストフィールドに質問を入力してAI APIへ送信する | 新規 |
| 2 | AI回答表示 | AIがマニュアルベースの回答を吹き出し形式で表示する（マークダウン対応） | 新規 |
| 3 | 質問サジェスト表示 | 会話開始時によく聞かれる質問を最大5件チップ形式で提示する | 新規 |
| 4 | 関連FAQ誘導 | AI回答に関連するFAQリンクを最大3件表示し、P003へ遷移できる | 新規 |
| 5 | フォールバック（AI未解決時） | AIが回答できない場合にサポートデスク連絡先バナーをチャット内に自動挿入する | 新規 |
| 6 | 会話履歴表示 | 同一セッション内のチャット履歴を時系列で表示する | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| AI質問入力・送信 | 質問テキスト（テキスト入力フィールド）※最大200文字。空白のみの入力は送信ボタンを無効化（disabled）。遷移元がP003の場合はFAQ ID（URLパラメータ）も入力として受け取る | バリデーション通過後、質問テキストをAI APIへ送信。マニュアルデータをシステムプロンプトとして付与。FAQ IDが存在する場合は該当FAQの内容を追加コンテキストとして付与し回答生成 | ユーザー吹き出しの即時表示 → ローディングインジケーター表示 → AI回答吹き出し表示 |
| AI回答表示 | AI APIレスポンス（テキスト） | レスポンスをパース・マークダウン変換（箇条書き・太字・改行）してHTML描画 | AI吹き出し（マークダウン対応テキスト）の表示。最新メッセージへ自動スクロール |
| 質問サジェスト表示 | なし（ページ初期表示） | よく聞かれる質問リストを静的データまたはAPIから取得 | 横スクロール可能なチップボタン（最大5件）の表示 |
| 関連FAQ誘導 | AI APIレスポンスに含まれる関連FAQ IDリスト | レスポンスから関連FAQ IDを抽出し、FAQ名を取得 | AI吹き出し直下に関連FAQリンクを最大3件表示 |
| フォールバック（AI未解決時） | AI APIレスポンス（回答不可フラグ） | APIレスポンスに回答不可フラグが含まれることを検知 | サポートデスク連絡先バナー（電話番号・フォームリンク）をそのターンのAI吹き出し直後に挿入 |
| 会話履歴表示 | セッション内の全送受信データ | セッション中のメッセージを時系列配列で保持・描画。セッション終了時は破棄 | 全会話履歴のスクロール表示（ユーザー吹き出し右寄せ・AI吹き出し左寄せ） |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| チャット入力フォーム | AI質問入力・送信 | `空（初期）` → `入力中（テキストあり・送信ボタン有効化）` → `送信中（入力欄クリア・無効化）` → `送信完了（再び入力可）` |
| 送信ボタン | AI質問入力・送信 | `無効（入力なし or 空白のみ）` → `有効（有効文字1文字以上・最大200文字）` → `ローディング（送信中・スピナー表示）` → `有効（回答受信後）` |
| ローディングインジケーター | AI回答表示 | `非表示` → `表示（送信後〜API応答受信まで）` → `非表示（回答描画後）` |
| 質問サジェストチップ | 質問サジェスト表示 | `表示（セッション開始・未送信時）` → `非表示（初回メッセージ送信後、以降は表示しない）` |
| 関連FAQリンク | 関連FAQ誘導 | `非表示（関連FAQなし時）` → `表示（関連FAQあり時、AI吹き出し直下）` |
| サポートデスク連絡先バナー | フォールバック（AI未解決時） | `非表示（通常時）` → `表示（AI未解決ターンの直後に挿入・以降セッション内で固定表示）` |
| 電話番号リンク | フォールバック（AI未解決時） | `デフォルト` → `タップ（OS電話アプリを起動）` |
