# 要件定義書 v2: P004 AIチャット画面

> DB設計を踏まえた要件定義書の更新

## 目的

入居者がテキストで自由に質問し、AIがマニュアルをもとに即座に回答するチャットインターフェースを提供する。AIが回答できない場合はサポートデスクへの連絡先をチャット内にシームレスに挿入し、有人対応へ迷わず引き継げるようにする。スマホキーボード表示時も入力フォームが見え操作できるモバイルファースト設計を徹底する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | AI質問入力・送信 | テキストフィールドに質問を入力してAI APIへ送信する | DB関連テーブル: `chat_sessions`（CREATE: 初回送信時に新規セッションを生成）、`chat_messages`（CREATE: ユーザーメッセージを保存）、`faqs`（READ: P003からのFAQ IDがある場合、コンテキスト本文を取得） |
| 2 | AI回答表示 | AIがマニュアルベースの回答を吹き出し形式で表示する（マークダウン対応） | DB関連テーブル: `chat_messages`（CREATE: AI回答メッセージを保存） |
| 3 | 質問サジェスト表示 | 会話開始時によく聞かれる質問を最大5件チップ形式で提示する | DB関連テーブル: `question_suggestions`（READ: display_order ASC で最大5件取得） |
| 4 | 関連FAQ誘導 | AI回答に関連するFAQリンクを最大3件表示しP003へ遷移できる | DB関連テーブル: `faqs`（READ: AI APIレスポンスに含まれるFAQ IDリストで title を取得） |
| 5 | フォールバック（AI未解決時） | AIが回答できない場合にサポートデスク連絡先バナーをチャット内に自動挿入する | DB関連テーブル: `chat_messages`（UPDATE: is_unresolved=true を設定）、`properties`（READ: property_id に紐づく support_phone・support_form_url を取得） |
| 6 | 会話履歴表示 | 同一セッション内のチャット履歴を時系列で表示する | DB関連テーブル: `chat_messages`（READ: session_id で絞り込み、sent_at ASC で取得） |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| AI質問入力・送信 | 質問テキスト（最大200文字、空白のみ不可）＋FAQ ID（P003からの遷移時のみ） | バリデーション通過後、`chat_sessions` に新規セッションをCREATE（初回のみ）。`chat_messages` にユーザーメッセージをCREATE。FAQ IDがある場合は `faqs` から body を取得して追加コンテキストとしてAI APIへ付与し回答生成 | ユーザー吹き出しの即時表示 → ローディング → AI回答吹き出し表示 | `chat_sessions` CREATE, `chat_messages` CREATE, `faqs` READ（FAQ IDあり時） |
| AI回答表示 | AI APIレスポンス（テキスト・回答不可フラグ・関連FAQ IDリスト） | レスポンスをパース・マークダウン変換してHTML描画。AI回答を `chat_messages` にCREATE | AI吹き出し（マークダウン対応テキスト）の表示。最新メッセージへ自動スクロール | `chat_messages` CREATE |
| 質問サジェスト表示 | なし（ページ初期表示） | `question_suggestions` を display_order ASC で最大5件取得 | 横スクロール可能なサジェストチップ（最大5件）の表示 | `question_suggestions` READ |
| 関連FAQ誘導 | AI APIレスポンスに含まれる関連FAQ IDリスト | FAQ IDリストで `faqs` から title を取得 | AI吹き出し直下に関連FAQリンクを最大3件表示 | `faqs` READ |
| フォールバック（AI未解決時） | AI APIレスポンス（回答不可フラグ） | 回答不可フラグを検知し、対象 `chat_messages` の is_unresolved を true に UPDATE。`faqs.property_id` 経由で `properties` の support_phone・support_form_url を取得 | サポートデスク連絡先バナー（電話番号・フォームリンク）をAI吹き出し直後にチャット内挿入 | `chat_messages` UPDATE, `properties` READ |
| 会話履歴表示 | セッション内の全送受信データ | `chat_messages` を session_id で絞り込み、sent_at ASC で全件取得して時系列描画 | 全会話履歴のスクロール表示（ユーザー吹き出し右寄せ・AI吹き出し左寄せ） | `chat_messages` READ |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| チャット入力フォーム | AI質問入力・送信 | なし（入力値はクライアント側で保持） |
| 送信ボタン | AI質問入力・送信 | なし（バリデーション通過後に`chat_sessions`・`chat_messages`へ書き込み） |
| ローディングインジケーター | AI回答表示 | なし（AI API応答待ち中のUI状態） |
| 質問サジェストチップ | 質問サジェスト表示 | `question_suggestions`（ページ初期表示時に取得。初回送信後は非表示） |
| 関連FAQリンク | 関連FAQ誘導 | `faqs`（AI回答受信後に関連FAQ IDで取得。なし時は非表示） |
| サポートデスク連絡先バナー | フォールバック（AI未解決時） | `chat_messages`（is_unresolved=true 更新後に表示）、`properties`（連絡先データの取得元） |
| 電話番号リンク | フォールバック（AI未解決時） | なし（タップでOS電話アプリを起動） |
