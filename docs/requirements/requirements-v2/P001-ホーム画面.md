# 要件定義書 v2: P001 ホーム画面

> DB設計を踏まえた要件定義書の更新

## 目的

入居者のエントリーポイント。キーワード検索・FAQカテゴリ選択・AIチャット起動・よく見られるFAQ表示の4つの導線を提供し、入居者が最短経路で自己解決フローに入れるようにする。スマホの片手操作を優先したモバイルファーストな設計とする。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | キーワード検索 | 検索窓にキーワードを入力してP002へ遷移する | DB関連テーブル: なし（クエリパラメータをP002へ渡すのみ） |
| 2 | FAQカテゴリ選択 | カテゴリカードをタップしてP002（カテゴリフィルタ済み）へ遷移する | DB関連テーブル: `faq_categories`（READ: カテゴリ一覧・アイコン取得） |
| 3 | AIチャット起動 | 「AIに聞く」ボタンからP004へ遷移する | DB関連テーブル: なし（ルーティングのみ） |
| 4 | よく見られるFAQ表示 | アクセス数上位のFAQを最大5件リスト表示しP003へ遷移できる | DB関連テーブル: `faqs`（READ: is_published=true かつ property_id 条件で access_count DESC 上位5件取得） |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| キーワード検索 | 検索キーワード（テキスト、最大50文字、空白のみ不可） | バリデーション通過後、キーワードをクエリパラメータとしてP002へルーティング | P002（検索結果画面）への遷移 | なし |
| FAQカテゴリ選択 | カテゴリID（タップ操作） | カテゴリIDをクエリパラメータとしてP002へルーティング | P002（カテゴリフィルタ済み）への遷移 | `faq_categories` READ |
| AIチャット起動 | タップ操作 | P004へルーティング | P004（AIチャット画面）への遷移 | なし |
| よく見られるFAQ表示 | なし（ページロード時） | `faqs` テーブルから is_published=true かつ対象 property_id の FAQ を access_count DESC で上位5件取得 | FAQタイトルのリスト表示（最大5件） | `faqs` READ |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| 検索バー | キーワード検索 | なし |
| 検索ボタン | キーワード検索 | なし |
| FAQカテゴリカード | FAQカテゴリ選択 | `faq_categories`（ページロード時にカテゴリ一覧を取得して描画） |
| よく見られるFAQリスト | よく見られるFAQ表示 | `faqs`（ページロード時に上位5件を取得。ローディング・エラー状態に応じて表示切り替え） |
| 「AIに聞く」ボタン | AIチャット起動 | なし |
