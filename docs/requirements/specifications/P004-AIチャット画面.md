# 仕様書: P004 AIチャット画面

## 目的

入居者がテキストで自由に質問し、AIがマニュアルをもとに即座に回答するチャットインターフェースを提供する。AIが回答できない場合はサポートデスクへの連絡先をシームレスに提示し、有人対応へ迷わず引き継げるようにする。スマホの片手操作を最優先に考慮したモバイルファーストなUIとする。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | AI質問入力・送信 | テキストフィールドに質問を入力してAIへ送信する |
| 2 | AI回答表示 | AIがマニュアルベースの回答を吹き出し形式で表示する |
| 3 | 質問サジェスト表示 | 会話開始時に「よく聞かれる質問」を最大5件ボタン形式で提示する |
| 4 | 関連FAQ誘導 | AI回答に関連するFAQリンクを最大3件表示し、P003へ遷移できる |
| 5 | フォールバック（AI未解決時） | AIが回答できない場合にサポートデスクの電話番号・問い合わせフォームを自動表示する |
| 6 | 会話履歴表示 | 同一セッション内のチャット履歴を時系列で表示する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| チャット入力フォーム | テキスト入力フィールド＋送信ボタン（紙飛行機アイコン）。スマホキーボード表示時も入力欄が見える位置に固定 | 画面最下部（固定） |
| チャット吹き出し（ユーザー） | ユーザーの質問を右寄せ吹き出しで表示 | チャット履歴領域（右側） |
| チャット吹き出し（AI） | AIの回答を左寄せ吹き出しで表示。マークダウン（箇条書き・太字）対応 | チャット履歴領域（左側） |
| 質問サジェストボタン | 「エアコンの使い方は？」などよく聞かれる質問を横スクロールのチップボタンで表示 | チャット開始時のみ、入力フォームの上に表示 |
| 関連FAQリンク | AI回答の下に「関連するFAQ」として最大3件のリンクを表示 | AI吹き出しの直下 |
| サポートデスク連絡先バナー | AI未解決時に「この質問はサポートデスクにお問い合わせください」とバナー表示。電話番号（タップで発信）＋フォームリンクを含む | AI未解決時にチャット履歴内に自動挿入 |
| ローディングインジケーター | AI回答生成中を示すアニメーション（点滅する3点）| AI吹き出し位置に表示 |
| ヘッダー | 「AIアシスタント」などのタイトル＋ホームへの戻るリンク | 画面最上部（固定） |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| AI質問入力・送信 | チャット入力フォーム | テキスト入力後に送信ボタンタップ or Enterで質問送信。ユーザー吹き出しが即時表示されAIがローディング状態になる |
| AI回答表示 | チャット吹き出し（AI）、ローディングインジケーター | API応答後にローディングが消えAI吹き出しで回答を表示。長文は自動折り返し |
| 質問サジェスト表示 | 質問サジェストボタン | チップボタンタップで入力フォームにテキストを自動入力して送信。初回メッセージ送信後は非表示になる |
| 関連FAQ誘導 | 関連FAQリンク | リンクタップでFAQ詳細画面（P003）へ遷移 |
| フォールバック（AI未解決時） | サポートデスク連絡先バナー | AIが「回答できません」と判断したターンの直後にバナーをチャット内に自動挿入。電話番号タップで発信、フォームリンクタップで問い合わせフォームへ遷移 |
| 会話履歴表示 | チャット吹き出し（ユーザー・AI） | セッション中は全履歴をスクロールで閲覧可能。最新メッセージは自動スクロールで表示 |

## 画面遷移

- 遷移先: P003（FAQ詳細画面、関連FAQリンクから）
- 遷移元: P001（ホーム画面の「AIに聞く」ボタン）、P002（0件時の誘導バナー）、P003（「AIに詳しく聞く」ボタン）
