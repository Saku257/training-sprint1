# 仕様書: P002 検索結果画面

## 目的

キーワード検索・カテゴリ選択の結果を一覧表示し、入居者が目的のFAQを素早く特定してP003（FAQ詳細画面）へ進めるようにする。結果が0件の場合はAIチャットへスムーズに誘導する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | 検索結果一覧表示 | 入力キーワードまたはカテゴリに合致するFAQをリスト形式で表示する |
| 2 | 検索キーワード再入力 | 検索バーを上部に常に表示し、キーワードを修正して再検索できる |
| 3 | FAQ詳細への遷移 | 結果リストの各アイテムをタップしてP003（FAQ詳細画面）へ遷移する |
| 4 | 0件時のAIチャット誘導 | 検索結果が0件の場合、「AIに聞く」ボタンとメッセージを表示してP004へ誘導する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| 検索バー | 現在の検索キーワードを表示・編集可能なフィールド。クリアボタン付き | 画面最上部（固定） |
| 検索結果件数 | 「〇件見つかりました」のテキスト表示 | 検索バーの直下 |
| 検索結果リスト | FAQ質問タイトル＋カテゴリタグ＋冒頭テキスト（2行）のカード形式リスト | 件数表示の下、スクロール可能 |
| 「AIに聞く」誘導バナー | 結果0件時に「見つかりませんでしたか？AIに質問してみましょう」と表示するバナー＋ボタン | 0件時のみ、リスト領域に表示 |
| ホームへ戻るリンク | ホーム画面（P001）へ戻るナビゲーション | ヘッダー左端（←アイコン） |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| 検索結果一覧表示 | 検索結果リスト | 画面表示時に自動で結果を描画。スクロールで全件閲覧可能 |
| 検索キーワード再入力 | 検索バー | キーワード修正後に検索ボタンタップ or Enter で再検索・結果更新 |
| FAQ詳細への遷移 | 検索結果リスト（各カード） | カードタップでFAQ詳細画面（P003）へ遷移 |
| 0件時のAIチャット誘導 | 「AIに聞く」誘導バナー | バナー内ボタンタップでAIチャット画面（P004）へ遷移 |

## 画面遷移

- 遷移先: P003（FAQ詳細画面）、P004（AIチャット画面）
- 遷移元: P001（ホーム画面）
