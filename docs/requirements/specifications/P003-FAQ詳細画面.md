# 仕様書: P003 FAQ詳細画面

## 目的

FAQの詳細な回答・手順を表示し、入居者がその場で問題を自己解決できる情報を提供する。解決できなかった場合はAIチャット（P004）またはサポートデスクへの連絡先を提示し、次のアクションへ迷わず進めるようにする。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | FAQ詳細表示 | 質問タイトル・回答本文（テキスト・手順・画像）を表示する |
| 2 | 解決フィードバック | 「解決できた / できなかった」をユーザーが回答し、満足度データを収集する |
| 3 | AIチャットへの誘導 | 「さらに詳しく聞く」ボタンからP004（AIチャット画面）へ遷移する |
| 4 | サポートデスク連絡先表示 | 電話番号・問い合わせフォームリンクをページ下部に常時表示する。「解決できなかった」選択時は強調表示に切り替える |
| 5 | 関連FAQ表示 | 関連する他のFAQを最大3件表示し、P003内で別FAQへ遷移できる |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| FAQタイトル | 質問文を大きなフォントで表示 | コンテンツ上部 |
| カテゴリタグ | 「設備」「ゴミ出し」などのタグバッジ | タイトルの直下 |
| 回答本文 | テキスト・番号付き手順・画像を含む回答コンテンツ。モバイルで読みやすい行間・フォントサイズ | タグの下、メインコンテンツ領域 |
| フィードバックボタン | 「👍 解決できた」「👎 解決できなかった」の2択ボタン | 回答本文の直下 |
| 「AIに詳しく聞く」ボタン | AIチャットへ遷移するセカンダリCTAボタン | フィードバックの下 |
| サポートデスク連絡先 | 電話番号（タップで発信）＋問い合わせフォームリンク。常時表示 | ページ下部（常時表示）。「解決できなかった」選択後は背景色変更・強調表示 |
| 関連FAQリスト | 関連する質問のリンクリスト（最大3件） | ページ最下部 |
| 戻るリンク | 検索結果画面（P002）またはホーム（P001）へ戻るナビゲーション | ヘッダー左端 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| FAQ詳細表示 | FAQタイトル・カテゴリタグ・回答本文 | ページ表示時に自動描画。画像は遅延ロード |
| 解決フィードバック | フィードバックボタン | ボタンタップで選択状態に変化し、バックエンドへ送信。「解決できなかった」タップ時はサポートデスク連絡先を強調表示 |
| AIチャットへの誘導 | 「AIに詳しく聞く」ボタン | タップでAIチャット画面（P004）へ遷移。現在のFAQ情報をコンテキストとして引き継ぎ |
| サポートデスク連絡先表示 | サポートデスク連絡先 | 電話番号タップでOS標準の電話アプリを起動。フォームリンクタップで問い合わせフォームへ遷移 |
| 関連FAQ表示 | 関連FAQリスト | 各リンクタップで別のFAQ詳細画面（P003）へ遷移 |

## 画面遷移

- 遷移先: P004（AIチャット画面）、P003（別FAQ詳細、関連FAQから）
- 遷移元: P002（検索結果画面）、P001（よく見られるFAQから）
