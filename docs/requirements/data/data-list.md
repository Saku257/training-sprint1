## エンティティ関係の概要

```
物件 1 ─── N サポートデスク連絡先（物件テーブルに含む）
物件 1 ─── N FAQ

FAQカテゴリ 1 ─── N FAQ
FAQ M ─── N タグ（中間テーブル: FAQ_タグ）

FAQ 1 ─── N フィードバック
FAQ 1 ─── N よく見られるFAQ（FAQアクセス数で動的生成）

チャットセッション 1 ─── N チャットメッセージ

質問サジェスト（独立テーブル）
```

## 補足

- **FAQ ID** はシステム全体の中核データ。P002→P003→P004をまたいで伝播するため、URL設計・API設計の基点となる
- **チャットメッセージはセッション終了時に破棄**（要件定義書v1 #19 に準拠）。ただしエスカレーション分析用途のログ保持はSprint 2以降で検討
- **物件IDの保持方法**（URLサブドメイン・パスパラメータ・セッション）はDB設計・API設計フェーズで確定する
