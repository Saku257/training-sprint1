# 要件定義書: P001 ホーム画面

## 目的

入居者のエントリーポイント。キーワード検索・FAQカテゴリ選択・AIチャット起動・よく見られるFAQ表示の4つの導線を提供し、入居者が最短経路で自己解決フローに入れるようにする。スマホの片手操作を優先したモバイルファーストな設計とする。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | キーワード検索 | 検索窓にキーワードを入力してP002（検索結果画面）へ遷移する | 新規 |
| 2 | FAQカテゴリ選択 | カテゴリカードをタップしてP002（カテゴリフィルタ済み）へ遷移する | 新規 |
| 3 | AIチャット起動 | 「AIに聞く」ボタンからP004（AIチャット画面）へ遷移する | 新規 |
| 4 | よく見られるFAQ表示 | アクセス数上位のFAQを最大5件リスト表示し、P003へ遷移できる | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| キーワード検索 | 検索キーワード（テキスト入力）※最大50文字。空白のみの入力は検索を実行しない | バリデーション通過後、キーワードをクエリパラメータとしてP002へ渡す | P002（検索結果画面）への遷移 |
| FAQカテゴリ選択 | カテゴリID（タップ操作） | カテゴリIDをクエリパラメータとしてP002へ渡す | P002（カテゴリフィルタ済み）への遷移 |
| AIチャット起動 | タップ操作 | P004へのルーティング | P004（AIチャット画面）への遷移 |
| よく見られるFAQ表示 | なし（ページロード時） | アクセス数上位のFAQをAPIから取得（上位5件） | FAQタイトルのリスト表示 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| 検索バー | キーワード検索 | `空（初期）` → `入力中（テキストあり・クリアボタン出現）` → `送信（P002へ遷移）` |
| 検索ボタン | キーワード検索 | `無効（入力なし or 空白のみ）` → `有効（有効文字1文字以上・最大50文字）` → `ローディング（送信中）` |
| FAQカテゴリカード | FAQカテゴリ選択 | `デフォルト` → `タップ中（押下エフェクト）` → `遷移（P002へ）` |
| よく見られるFAQリスト | よく見られるFAQ表示 | `ローディング（スケルトン表示）` → `表示（データあり）` → `エラー（取得失敗時：「読み込みに失敗しました」メッセージ）` |
| 「AIに聞く」ボタン | AIチャット起動 | `デフォルト` → `タップ中（押下エフェクト）` → `遷移（P004へ）` |
