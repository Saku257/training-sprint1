# 要件定義書: P003 FAQ詳細画面

## 目的

FAQの詳細な回答・手順を表示し、入居者がその場で問題を自己解決できる情報を提供する。解決できた場合はフィードバックを収集し、解決できなかった場合はAIチャット（P004）またはサポートデスクへの連絡先を提示して次のアクションへ迷わず進めるようにする。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | FAQ詳細表示 | 質問タイトル・カテゴリ・回答本文（テキスト・手順・画像）を表示する | 新規 |
| 2 | 解決フィードバック | 「解決できた / できなかった」を入居者が回答し、満足度データを収集する | 新規 |
| 3 | AIチャットへの誘導 | 「AIに詳しく聞く」ボタンからP004へ遷移し、現在のFAQコンテキストを引き継ぐ | 新規 |
| 4 | サポートデスク連絡先表示 | 解決できなかった場合に電話番号・問い合わせフォームリンクを提示する | 新規 |
| 5 | 関連FAQ表示 | 関連する他のFAQを最大3件表示し、P003内で別FAQへ遷移できる | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| FAQ詳細表示 | FAQ ID（URLパラメータ） | FAQ IDでFAQデータを取得。回答本文のマークダウンをHTMLへ変換 | タイトル・カテゴリタグ・回答本文（テキスト・番号付き手順・画像）の表示 |
| 解決フィードバック | 「解決できた / できなかった」選択（タップ） | FAQ IDとフィードバック値（solved / unsolved）をバックエンドへ送信し満足度DBを更新 | 選択ボタンのハイライト変化。「解決できなかった」選択時はサポートデスク連絡先を強調表示 |
| AIチャットへの誘導 | タップ操作 | 現在のFAQ IDをコンテキストパラメータとしてP004へルーティング | P004（AIチャット画面）への遷移。AIに現在のFAQ内容がコンテキストとして渡される |
| サポートデスク連絡先表示 | ページロード時（常時表示） | 物件IDに紐づくサポートデスクの連絡先データを取得 | 電話番号（タップでOS電話アプリ起動）・問い合わせフォームURL（外部リンク）をページ下部に常時表示。「解決できなかった」選択時は強調スタイルに切り替え |
| 関連FAQ表示 | FAQ ID（ページロード時） | FAQ IDに関連するFAQを最大3件取得（タグ・カテゴリベースのレコメンド） | 関連FAQのタイトルリンクリスト（最大3件） |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| FAQ本文 | FAQ詳細表示 | `ローディング（スケルトン表示）` → `表示（データあり）` → `エラー（「読み込みに失敗しました」メッセージ）` |
| フィードバックボタン（解決できた） | 解決フィードバック | `未選択（初期）` → `選択中（👍ハイライト・押下エフェクト）` → `送信完了（選択固定・再タップ不可）` |
| フィードバックボタン（解決できなかった） | 解決フィードバック | `未選択（初期）` → `選択中（👎ハイライト）` → `送信完了（選択固定）` |
| サポートデスク連絡先 | サポートデスク連絡先表示 | `常時表示（ページ下部・控えめなスタイル）` → `強調表示（「解決できなかった」選択時・背景色変更）` |
| 関連FAQリスト | 関連FAQ表示 | `ローディング（スケルトン）` → `表示（リンクリスト）` → `非表示（関連FAQなし時）` |
| 「AIに詳しく聞く」ボタン | AIチャットへの誘導 | `デフォルト` → `タップ中（押下エフェクト）` → `遷移（P004へ）` |
