# 仕様書: P001 ホーム画面

## 目的

入居者のエントリーポイント。キーワード検索・FAQカテゴリ一覧・AIチャットへのアクセスを提供し、入居者が最短経路で自己解決フローへ入れるようにする。スマホで片手操作できるモバイルファーストなレイアウトを基本とする。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | キーワード検索 | 検索窓にキーワードを入力してP002（検索結果画面）へ遷移する |
| 2 | FAQカテゴリ選択 | 「設備」「ゴミ出し」「駐車場」などカテゴリ別に絞り込みP002へ遷移する |
| 3 | AIチャット起動 | 「AIに聞く」ボタンからP004（AIチャット画面）へ遷移する |
| 4 | よく見られるFAQ表示 | アクセス数上位のFAQを最大5件表示し、P003（FAQ詳細画面）へ遷移できる |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| 検索バー | テキスト入力フィールド＋検索ボタン。プレースホルダーに「例：エアコンの使い方」と表示 | 画面上部（ヘッダー直下）、視線が最初に向かう位置 |
| FAQカテゴリカード | アイコン＋カテゴリ名のカードグリッド（2列）。タップ領域を大きく確保 | 検索バーの下、スクロールなしで視認できる位置 |
| 「AIに聞く」ボタン | 目立つ色のCTAボタン。チャットアイコン付き | カテゴリカードの下、または画面右下に固定（Floating Action Button） |
| よく見られるFAQリスト | 質問タイトルのリスト形式（最大5件）。各行がP003へのリンク | ページ下部 |
| ヘッダー | サービスロゴ・物件名を表示 | 画面最上部（固定） |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| キーワード検索 | 検索バー | キーワード入力後に検索ボタンタップ or Enterキーで検索結果画面（P002）へ遷移 |
| FAQカテゴリ選択 | FAQカテゴリカード | カードタップでそのカテゴリの検索結果画面（P002）へ遷移 |
| AIチャット起動 | 「AIに聞く」ボタン | ボタンタップでAIチャット画面（P004）へ遷移 |
| よく見られるFAQ表示 | よく見られるFAQリスト | 各行タップでFAQ詳細画面（P003）へ遷移 |

## 画面遷移

- 遷移先: P002（検索結果画面）、P003（FAQ詳細画面）、P004（AIチャット画面）
- 遷移元: なし（エントリーポイント）
