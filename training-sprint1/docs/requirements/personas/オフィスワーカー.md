# ペルソナ: オフィスワーカー（テナント入居者）

## ユーザー属性

| 項目 | 内容 |
|------|------|
| 名前 | 田中 美咲（たなか みさき） |
| 年齢 | 30代 |
| 職業 | 営業部スタッフ |
| 部門 | 営業部 |
| 勤務地 | 三菱地所管理ビル内テナントオフィス（都市部） |
| 技術スキル | 中程度（スマホ・PCは日常的に使うが、システム操作は苦手） |

## 目標・ゴール

- 業務中に発生したトラブルや疑問を、誰かに聞かずに素早く自己解決したい
- 分厚いマニュアルを読まなくても、必要な情報に瞬時にアクセスしたい
- 電話保留で待たされることなく、問題をその場で解決して業務に戻りたい

## 課題

- 業務中で手が離せず、紙のテナントマニュアルから該当ページを探す時間がない
- トラブル（例：エアコンの水漏れ、ゴミの捨て方が分からない）が起きるたびに管理側に電話しなければならず、業務が中断してしまう
- マニュアルは情報量が多すぎて画像中心のため、どこに何が書いてあるか分からない

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| トラブル発生時の即時検索 | 月1〜3回 | エアコン不具合・水漏れなど突発的なトラブル時にスマホやPCからすぐ調べたい |
| ゴミ出し・設備利用ルールの確認 | 月1〜2回 | 入居初期や季節の変わり目に分別方法・ゴミ収集日などを確認したい |
| 入居後の各種手続き確認 | 数回/年 | 駐車場利用や来客対応など、ルールを忘れたタイミングで参照したい |

## ペルソナの心情

> 「忙しい業務の合間にトラブルが起きると本当に焦る。マニュアルをめくってる時間も、電話が繋がるまで待つ時間も惜しい。スマホでパッと調べて、すぐ解決できれば、それだけでいい。」
