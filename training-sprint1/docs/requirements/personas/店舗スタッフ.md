| 項目 | 内容 |
|------|------|
| 名前 | 山本 浩二（やまもと こうじ） |
| 年齢 | 20代 |
| 職業 | 飲食店スタッフ（シフト制） |
| 部門 | 店舗運営 |
| 勤務地 | 三菱地所管理ビル内商業テナント（飲食店） |
| 技術スキル | 低〜中程度（スマホは使い慣れているが、PCは不得意） |

## 目標・ゴール

- 営業中のトラブルをその場でスマホ一つで即座に解決し、お客様への影響を最小限に抑えたい
- 店長や先輩に確認しなくても、ルールや手順を自分で調べて行動したい
- 分厚いマニュアルを読まずに、知りたいことだけをすぐ取り出せる環境がほしい

## 課題

- 営業中（特にピーク時）にトラブルが発生しても、紙のマニュアルをめくっている時間は一切ない
- ゴミの分別ルールや設備の操作方法など、入居時に一度説明を受けても忘れてしまう
- 管理側に電話しても繋がらないことがあり、急ぎのトラブル時に頼れる情報源がなくて困る

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| 営業中の突発トラブル対応 | 月2〜5回 | 排水詰まり・設備故障など、営業中にスマホで即調べて対処したい |
| ゴミ出し・廃棄物処理の確認 | 週1〜2回 | 分別区分・収集曜日・出し方のルールを毎回確認している |
| 新人スタッフへの情報共有 | シフト毎 | 入れ替わりの激しいスタッフに設備利用ルールを簡単に共有したい |

## ペルソナの心情

> 「お客さんの前でトラブルが起きたとき、マニュアルなんて探してられない。スマホで一言入力したら答えが出てくれれば、それだけで助かる。電話が繋がらなくても自分で解決できれば、もっと安心して仕事ができる。」
